# Dead Signal — Build Lab Color Flow Preview v2

This is an isolated concept preview for the Build Lab color treatment. It is intentionally much closer to the approved render than v1 and deliberately removes the extra visual zoning that made v1 feel too busy.

## Rendered preview

[Open the interactive concept](https://htmlpreview.github.io/?https://github.com/raiinman/dead-signal/blob/main/concepts/build-lab-color-flow-preview-v2/index.html)

## Design target

- preserve the current Build Lab structure
- mostly black / graphite workstation shell
- red + cyan remain the global Dead Signal accents
- color concentrated in populated loadout cards and the Loadout Report
- rarity color on actual items only
- evidence/status colors stay separate from rarity
- no extra metric strip or rainbow section bars
- subtle color-flow treatment in the hero only
- much lower visual density than v1

This folder is not part of production deployment and does not alter `/build-planner/`.
