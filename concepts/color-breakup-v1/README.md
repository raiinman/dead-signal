### What this concept is testing

- stronger section separation
- richer Dead Signal color zoning without losing the dark tactical identity
- red as the primary brand color
- amber/orange for weapons and armor emphasis
- cyan/teal for Calibration/data-integrity systems
- purple for mods/reporting
- green for Deviations/status
- more visual depth and layered hierarchy
- clearer distinction between planner, tools, database, guides, and future community surfaces

The mockup includes light interactions for **MY GEAR vs GOD ROLL**, card focus, build selection, and smooth navigation so the layout can be judged as a page rather than only as a still render.
