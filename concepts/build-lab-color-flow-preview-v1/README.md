## What this preview is testing

- the current Build Lab structure with the stronger Color Flow visual language
- rarity color on item cards only: common gray, uncommon green, rare blue, epic purple, legendary gold
- evidence state separated from rarity: proven teal/green, review amber, blocked/error red
- red/copper weapons, steel/blue armor, purple Mods, gold Calibrations, teal Deviations, magenta Cradle Overrides
- stronger MY GEAR vs GOD ROLL distinction
- richer Loadout Report color coding
- subtle flow/energy treatment in the hero without recoloring the entire workstation shell
- a planner that becomes visually richer as the loadout fills in

The visible equipment and status values are **sample content for visual review only** and are not intended to replace or reconcile mined game data.
